I created Garden as a fork of a project called [Quartz, built by Jacky Zhao](https://quartz.jzhao.xyz/) in December 2023.

I was already aware of Knowledge Graphs due the products like Roam Research and Obsidian. Roam Research was very popular on Twitter back then, however it was paid. So people would use Obsidian as a free alternative.

Obsidian was a great place to write by itself. With Quartz, Jacky built a way to deploy Obsidian Vaults as websites!

Before Garden, I had another forked project as my blog - updating posts over there required me to write HTML and post. That was cumbersome, so I knew the value of having Quartz, write as Markdown in a system that acts like your CMS (no need to build a CMS) - and then deploy every time for Quartz to automatically script markdown files into HTML and make them suitable on browser. Also ensuring all Obsidian features like Tags, Dates, Markdown Formatting, and the very main the Graph could also be part of the website.

So now the website itself can function as a Knowledge Graph.

# The name Garden

I started calling it Garden because I imagined curious people visiting this website to simply explore. Like you visit a Garden, sometimes you have a specific goal like running but otherwise you would just look at the trees, birds and flowers around you. And stay as long as you wanted impromptu going wherever excites you.

# Upgrading the Version 4

I recently updated Quartz to version 4. This allowed a default Explorer section on right side on desktop and within hamburger menu for mobile. So users no longer need to click on my folders to explore.

Due to this update I do not really need the first page to be all link-y like it is right now. My primary goal when someone visits this Index page is that they **Subscribe** to my RSS feed which sends a list of all writings in past 7 days via email.

Every Sunday morning - you get to read some philosophy, my new projects or ideas, and adventures if I am travelling.

I did some custom development to make Garden more focused on this goal.

Other than explorer, the version 4 of Quartz brought Table of Contents visible on right side of desktop viewport. However this is not default available on mobile/tablet.
