This blog lists down a brief for all projects I have worked on,
### Raahi
A Map based UI interface for users to generate AI based travel itineraries and share them.
URL: https://planmytravel.netlify.app/
Role: Developer

![[raahi_homepage.png]]

**Features**
1. Maps Integration - use of geocoding, reverse geocoding, routing, polyline to plot routes, search suggestions for places, adding pointers to the map
2. UUID based authentication without email or phone numbers
3. Ability to save maps per user (more specifically - per user per browser)
4. Revisit or modify past saved maps
5. Generate Share Links for Maps and share over whatsapp
6. Pass query to LLM and generate response and communicate the response over UI
7. Caching Responses and retrieving with a key
8. Task management system for incoming queries
9. Feedback and Subscription prompts
10. Postgres DB integration via Supabase
11. Setting up CI/CD with Netlify and Render and Hosting the website
12. Integration of Google Analytics for tracking
13. Landing Page and other webpages
